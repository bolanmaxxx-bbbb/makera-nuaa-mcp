# 自由工艺流程

## 三个入口

第一次需求不明确时询问：“希望我根据目标推荐流程、从常用模板修改，还是按你已有的流程检查执行？”用户已经给出流程或偏好时直接复用，不重复询问。

引导推荐：先了解要得到什么、现有条件和优先级，例如精度、表面质量、少换刀、节省材料或加工时间；提出少量方案并解释代价。选择模板：使用workflow-menu.json中的起点，不把候选步骤全部视为必需。自定义：记录用户工序，指出具体缺口及影响，由用户选择修正方法。

默认使用通用job-template.json（job_kind=custom），workflow.mode为assisted/template/custom。只有选择单面板件的专用尺寸链时才用plate-part-template.json。不要把复杂任务硬塞进单面板件规则。

## 需求与工艺分开记录

requirements每项记录id、description、acceptance，以及满足方式resolution：

- operations：通过operation_ids中的一个或多个工序满足。
- verified_input：现成材料/零件/表面已经满足，记录evidence和confirmed_current；不能只因名义值相同就视为已验证。
- excluded_by_user：用户确实选择不做或缩小范围，记录reason及user_confirmed。保留排除项，让交付范围清楚可见。

例如“最终厚度符合图纸”是要求；先面铣、用已等厚原料、翻面加工或交由外部磨削是不同方法。表面文字任务可能根本没有改变厚度的要求。遇到图纸缺少关键尺寸或材料未知，先提问，不自行把它改成无需验收的目标。

通用要求示例（仅结构，不是现成验收结果）：

```json
{
  "id": "pocket-depth",
  "description": "型腔深度符合已确认图纸",
  "acceptance": "按图纸公差核对CAM深度，实际加工后测量",
  "resolution": "operations",
  "operation_ids": ["rough-pocket", "finish-pocket"]
}
```

## 组合工序与依赖

每个工序有唯一id、kind、depends_on和输入/输出基准说明。按依赖排序；同级互不影响的工序允许重排。移动某工序时，检查它的定位特征、支撑、剩余材料、刀具通道和验收数据是否仍成立。重新装夹的步骤设changes_setup=true，并记录reestablish_datum；基准变化要重新核对相关后续工序。

可定义kind为face、drill、contour、engrave、pocket、relief_3d、chamfer或其他明确名称。自定义名称可以进入草案；实际执行前必须有对应、经过验证的MCP适配器，不能由名称推断已经支持。

手工/外部步骤使用execution_mode=manual，并记录handoff和acceptance。它能进入完整计划，CAM阶段会保留未验收警告，不能冒充MCP执行；交付阶段须在同修订evidence.manual_steps中提供该id、verified=true和实际evidence记录。切换设备、外部软件或人工完成后，回读实际产物与条件，再更新计划和证据。用户须实际选择这种交接方式，不能把不支持的自动步骤自行改成人工步骤来消除能力缺口。

## 按需要选检查模块

| 模块 | 何时选用 | 关注事项与可选方法 |
|---|---|---|
| 目标与验收 | 所有任务 | 单位、方向、特征、公差、表面要求、用户要交付的阶段 |
| 定位与夹持 | 所有实际加工方案 | 原点、夹具、禁入区、稳定性、刀具可达性；不固定某一种夹法 |
| 孔加工 | 有孔特征 | 钻/铣/扩/铰的选择、通盲孔、孔底形状、钻尖补偿、退屑、背面支撑 |
| 型腔与台阶 | 有凹槽或台阶 | 底厚、角半径、入刀、粗精余量、残料和排屑 |
| 外形与分离 | 要制取独立零件 | 轮廓覆盖、连接筋/底皮/夹持等保留方案、分离修整及支撑变化 |
| 厚度形成 | 成品厚度是要求且需确认其形成方式 | 已等厚原料、面铣、翻面或外部磨削；只对所选方法采集相应测量 |
| 三维表面 | 曲面或浮雕 | 粗精刀形、残留高度、残料、曲率、干涉；不强迫用平面定厚链 |
| 多装夹 | 翻面、重装夹或多面 | 基准传递、定位销/工装、装夹余量、关联公差、各装夹独立验证 |
| 薄壁/微小特征 | 特征容易失稳或小刀加工 | 支撑顺序、切削力、刀具伸出、排屑与冷却、分步验收 |
| 参数与策略 | 所有切削工序 | 材料与刀具依据、转速/进给/下刀/每层/步距；没有一套参数通用 |

测量方式按所需精度、装夹条件和可用工具选择：卡尺/千分尺、接触测头、基准面差值或其他有依据的方法。底面与顶面差值只是选项，局部测量也不能代替整片材料的平面度/厚度分布。

## 软件校验的作用和边界

通用校验检查目标覆盖、工序引用、依赖循环/顺序、翻面定位说明、当前服务能力、参数完整性及同修订证据。板件专用模板再检查实测厚度、定厚去除量和最终轮廓深度；纯表面模板不要求加工成独立零件。

通用校验不理解完整CAD实体和自由文字中的全部物理约束。目标“有关联工序”不等于该工序已在几何上满足目标；Codex还须读取模型、核对保存的具体参数，并在仿真和最终实测中验证。它是skill工作流中的检查器，尚未嵌入底层MCP强制执行，不能保证绕过skill的调用也被拦截。
