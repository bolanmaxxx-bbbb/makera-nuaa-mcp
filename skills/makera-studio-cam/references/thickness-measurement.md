# 加工点局部测厚（可选模块）

用户请求测厚、选择探头测量或需要核对当前加工点厚度时使用。不要求所有任务测厚，也不把测厚与面铣绑定。此模块提供测量计划、记录和只读计算；当前MCP没有移动、探测或设备反馈接口，不能据此声称已实现自动测厚。

## 基准面与测点

先辨别用户说的定位物和被测面。直角尺/夹具可帮助描述附近位置，真正的第一测面应是用户选定的**裸露垫板顶面**，而非直角尺、压块、螺钉或工件顶面。记录具体位置提示，但不把某用户的左上角、坐标或净空变为通用默认值。图像和“左上方”不足以建立机床坐标。

第二测面是当前装夹下加工点的材料顶面。Z向上时：

```text
加工点承托面Z = 基准测点垫板Z + 垫板从基准点到加工点的高度修正
局部材料厚度 = 加工点顶面Z − 加工点承托面Z − 已知垫层厚度
```

异地垫板测点不能无依据当作加工点底面。高度修正来自已测垫板平面/局部平整度或其他适合公差的依据，零修正也需说明依据。胶带、胶层、碎屑、悬空和夹紧挠曲会影响差值；间隙未知时保留未知，不填0。结果只代表所测加工点及当前装夹，不能宣称整板等厚、平整或将其直接当成测头标定。

## 先确定执行方式与当前条件

先读取实际get_capabilities。当前只能准备方案或分析用户提供的数据。未来有验证过的设备适配器时，才可在当前现场授权范围执行。用户也可以明确选择自行在软件MDI中操作、由Codex逐条指导；不得因为缺少接口就自动改为人工操作，更不能通过外部串口、任意Qt槽、模拟键盘或G-code发送绕过限制。

只问当前关键缺项，一般1–3项；下面技术字段由工具/现场证据逐步补全，不发整张问卷：

- 当前测头类型、标定和触发信号是否适用于两测面，主轴已停止。不同探头/刀具/标定不能混为同一高度链。
- 当前装夹、基准、机器/工件坐标、单位、正方向、偏置版本和实际锁存回报的坐标体系。显示大/小号坐标不能靠外观猜。回零、重启、换测头、改偏置/标定或移动工件/垫板后，重新核对受影响记录并换context/coordinate_epoch。
- 两个可接触测点的XY、垫板高度传递依据、垫层/间隙；重复性允许值和本任务允许的测量误差。重复性不等于准确度，误差估计还需考虑标定、平面传递、分辨率和装夹。

测头硬件与标定按对应机型官方说明核对，可查[Makera Z1快速入门](https://wiki.makera.com/en/Z1/QuickStart)。这份机型文档不是任意G-code方言的兼容性证明。

## 接近与探测顺序

1. 先读当前状态，清除未发送旧MDI（尤其残留增量模式指令），确认Idle与已知模态。保留原工作原点，不在两个测面之间自动改零/G92/G10。历史坐标、重启前位置、未确认的偏置不得直接复用。
2. 将用户要求的“表面上方20 mm”等记录为**探针尖端相对指定表面的接近净空目标**，不是机器Z20，也不是从当前位置盲发G91 Z20。先核对表面高度依据、轴行程、软限位、测头本体及直角尺/螺钉/工件最高障碍；未知时不能生成可执行移动行。净空可能需要提高，也可能超出行程，须先调整方案。
3. 先在已验证方向退至能跨越整条路线的净空高度，再XY移到裸露垫板测点；检查探针与本体均无碰撞，再分段接近。不得用跨夹具的XYZ斜向快移代替路线核对。接近进给与最后慢速有限行程探测分开，搜索行程和进给按当前测头/控制器验证，不能拿20 mm作盲探距离。
4. 在垫板顶面采集实际触发锁存位置，确认成功和Idle，再按已验证方式脱离、重复接触。重复计划通常每面2–3次，数量和允许极差由任务决定；单次只可形成暂算，不能标成重复性已验证。
5. 再退到跨越路线的已验证净空，移动到加工点，按同样条件测材料顶面及重复性。每次采集保留独立时间、原始回报、触发结果和完成后的Idle；不能用指令终点或回退后的DRO冒充接触坐标。
6. 成功后按已验证路线离开。只恢复原本已知的模态，保存测量证据；失败/状态未知时不得盲目发送恢复模态、自动退刀或重试。

若控制器方言已经验证，用户自行操作可使用该控制器支持的探测指令；不能仅因知道`G38.2`就推断本机支持。逐次只提供一条已核对的命令，待用户执行、反馈成功锁存报告（例如已验证格式的`PRB ... :1`）且Idle后再继续。`PRB ... :0`、ALARM、未触发、异常继续下降均停止后续；仍下降时使用物理急停。不得编写缺少当前坐标/行程/进给依据的一键运行NC。

## 记录与只读校核

复制[测量记录模板](../assets/thickness-measurement-template.json)到任务私有目录。`approach`记录路线规划，不参与厚度计算，也不由校核器批准运动。`context.id`只对应同一装夹、基准、坐标时期、偏置、探头和标定；任何一项变化即新建上下文，不把旧值换个标签继续用。

`readings`每次独立采集一项，按实际采集时间排序；至少包含：

```json
{
  "id": "独立采集标识",
  "context_id": "对应context.id",
  "surface": "backing_top或stock_top",
  "measured_at": "带时区的实际ISO时间",
  "raw_report": "完整保留的单次锁存回报",
  "acquisition_ok": true,
  "controller_state_after": "Idle"
}
```

只在证据支持时填写true或Idle。`report_format=grbl_prb`是**回报导入格式**，支持单个成功的三轴或附A轴PRB回报，不证明机型兼容；必须已确认回报坐标体系。有A轴时，各次回报的A必须一致，不混合三轴与四轴回报或旋转后的装夹数据。其他已验证适配器可用`latched_xyz`格式，在每条reading增加`latched_xyz_mm: {x,y,z}`（有A则保留a）与`trigger_success: true`，保留原始证据，不能从截图/指令终点猜数。

```text
python <本技能目录>/scripts/check_thickness_measurement.py <测厚记录.json>
```

只输出JSON，不连接设备、不改工程、不改job、不发送任何命令。退出0表示输入记录满足所选测量检查，2表示无效或缺项，3表示文件/结构错误。`record_valid`与`measurement_usable`分开：成功坐标可以暂算，但缺少重复性、垫板修正、垫层或精度依据时不得输出可交接的`stock_measurement`。脚本不能鉴别记录是否真实，也不检查碰撞或运动权限。

结果可用时输出兼容板件job的`stock_measurement`片段，`bottom_z_mm`已修正为**加工点处**的承托面；仍保留原始基准测点数据及修正依据。核对当前装夹与测点后，由Codex显式写入job.stock.measurement，增加修订，重新计算受影响的去除量和切深、刀路及下游证据。不要自动覆盖毛坯名义厚度、MKS毛坯或工件零点；“测厚检查通过”不等于CAM/现场加工已获通过。
