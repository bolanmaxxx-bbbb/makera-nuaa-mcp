# 圆棒双面微件：旧模型干扰与切深修复

适用：Studio 中在圆棒上制作带孔、正面环槽、背面凸台和连接筋的微件；尤其是换模型、换加工位置后，预览变成实心块、深柱或与目标无关的形状。此案例记录于2026-10-28，属于本机软件行为经验，不是厂商所有版本的通用结论。

## 已确认的原因与修复证据

工程同时保留旧的X=100整棒布局和新的X=65布局。旧模型虽隐藏，在X=65仍是实心棒，参与了三维去料计算。只更换几何引用或加工中心没有解决。

- 修复前，顶面粗、精浮雕运动最低Z约2.527879 mm，达不到目标主体顶面Z=0.5 mm。
- 保存修复前工程副本，删除已废弃的旧整棒模型，仅保留新的连体留筋布局，再重算。
- 顶面粗加工最低Z约0.00000156 mm、精加工最低Z=0；底面粗加工的最大深度限制由−1修正为0后，实际运动也到达Z≈0。该变化支持旧模型干扰的诊断。
- 用户随后认可了本次工件效果。该反馈不代表已经完成尺寸测量、碰撞认证或实切验收；不能由本案例推断0.05 mm偏心公差已达标。

## 续接、移位和替换模型的做法

1. 沿用已确认的尺寸、刀具和项目；先观察当前工程及保存内容，避免重复建立项目或重新询问已有信息。保存一份可恢复备份。
2. 枚举全部3D模型、可见性、UUID、变换后包围范围以及逐工序引用。区分最终保留实体、毛坯显示和过期模型；检查过期实体是否填满新窗口。隐藏状态不是排除证据。
3. 在备份后移除确已废弃的干扰模型。不要直接修改MKS内部矩阵或调用未知Qt槽。软件操作使用当前受支持接口；用户指定Computer Use时按该技能通过可见界面完成相应操作。
4. 整体换位置时同步核对目标模型、窗口、孔、槽中心线、背面凸台和清料边界。先用毛坯坐标统一描述，再分别转换到顶/底面；不能把屏幕镜像或相同输入值当作同一物理位置。
5. 重新计算所有受影响工序，等待原生生成完成后保存，再回读模型数量、引用、刀具、切深和实际轨迹范围。不能只移动模型后继续使用旧刀路，不能在生成未完成时用一次保存宣布完成。
6. 先单独预览顶面，再预览底面及组合去料。放大到微件而非整根棒，播放至末端，确认材料显示随进度更新；视需要隐藏刀具、关闭纹理并叠加目标模型。时间轴跳到末尾而材料未更新时，不能把静态画面当作最终去料结果。
7. 从正面、背面和侧面分别确认：2×2主体、完整贯通孔、环槽及孔边平台、背面圆柱凸台、两个连接筋和周围清空窗口。轨迹最小Z与包围框只能辅助诊断，不能证明全部形状正确。

如果旧模型已移除但仍不符，继续查当前面变换、刀具实际形状、边界/包含方式、最大深度限制和未重算的工序，不靠随机试切深修复。

## 本案例的几何坐标（mm）

以圆棒一端为轴向X=0、回转轴为Y=Z=0。源STL范围X=−57…57，节点平移X=+57后才得到毛坯X=0…114。主体中心X65与整个不对称微件包围框中心不同。

| 项目 | 本例数值 |
|---|---|
| 毛坯 | 6061，Ø8×114 |
| 主体 | X64…66、Y−1…1、Z−0.5…0.5 |
| 背面凸台 | 同轴Ø1，高0.5，尖端平面Z=−1 |
| 孔 | Ø0.85，中心X65、Y0 |
| 正面平台 | 孔缘至环槽内缘径向0.08 |
| 半圆环槽 | 截面R0.2、宽0.4、中心线Ø1.41、槽底Z=0.3 |
| 清空窗口 | X62…68、Y−3…3 |
| 两侧连接筋 | 沿X连接外棒，Y宽0.8、Z厚0.6（±0.3）；端部搭接0.05，属本例试算参数 |
| 整个微件包围框中心 | (65,0,−0.25)，不是主体中心(65,0,0) |

连体CAD包含保留圆棒、微件和两侧筋；生成报告显示一个连通体、封闭网格。这仅证明CAD拓扑，不证明筋的强度或刀具扫掠后仍保持同样尺寸。

## 本案例的工序与深度语义

刀具：T1平底Ø1.5/刃长4；T2平底Ø1/刃长4；T3钻Ø0.85/刃长5/柄3；T4球刀R0.2（刃径0.4）/刃长2/柄4。刀号及几何为本例记录，不设为其他任务默认刀库。

顶面保留：T1分层浮雕粗加工 → T2浮雕精加工 → T3贯通孔 → T4环槽中心线轮廓。底面保留：T1浮雕粗加工 → T2凸台外轮廓 → T1两侧清料。小槽、小孔分别加工，不能靠大平底刀浮雕代替；R0.2是半径而非刀径。

| 本例工序 | 原生输入/限制 | 对应运动高度 |
|---|---|---|
| 顶、底面浮雕清料 | startDepth=−4；启用的最大深度字段finishStepDown=0 | 各自面局部Z约4→0，受目标实体保护 |
| 顶面钻孔 | startDepth=−0.5，endDepth=1.5 | Z=0.5→−1.5，含穿透余量 |
| 顶面球刀环槽 | startDepth=−0.5，endDepth=−0.3 | 刀尖槽底Z=0.3 |
| 底面凸台轮廓 | startDepth=−1，endDepth=−0.5 | 底面局部Z=1→0.5 |
| 底面两侧清料 | startDepth=−1，endDepth=0 | 底面局部Z=1→0 |

顶底面局部Z均朝当前加工面外为正。底面运动必须结合面矩阵变回毛坯坐标，不能直接把底面正Z当作原毛坯正Z。上述最大深度0用于本例在轴线附近衔接的清料，不是所有四轴工程的正确值。

三维浮雕的复用endDepth字段可能没有实际意义；读启用的最大深度、finishStepDown和保存运动。二维起止深度按当前版本的定义转换后核对运动，不以两个带符号数字大小直接判断切削方向。详情提交后重新检查实际刀具，避免误用球刀加工主体外轮廓。

## 保存与验收边界

本机分度双面开发接口曾出现重开后切深改变的独立问题。本次修复旧模型干扰不代表重开问题已修好。不要为“验证持久化”盲目重开唯一的有效会话；先备份并保存回读。确需重开时使用隔离副本，比较打开前、内存当前值、再次保存后的值及实际轨迹。若当前接口返回`indexed_depth_changed_on_native_load`，保留源文件并停止该接口相关CAM写入，不能绕过保护继续保存。

软件修复不包含设置机床原点或发送加工。圆棒长度坐标、伸入卡爪长度、设备工作原点偏移是不同数值；不把CAM的X65直接填作设备偏移。设备回零也不等于找到回转轴Y/Z。当前现场数据不足时保留缺项，不用本例的软件结果宣称可以直接实切。
